# 自动化画面与对话资源

电脑/浏览器自动化沿用对话中的控制栏，不新增侧栏功能。工具上报实际 target 后，对话可跟随该窗口；正在执行时自动展开画中画，关闭画中画只停止预览，不停止任务。用户仍从控制栏暂停或接管。

## 画面来源

- 浏览器页签始终按 Relay 页签 ID 捕获，不能把页签 ID 当成桌面窗口 ID。
- Windows 用 HWND + 进程 ID 标识窗口，关闭、句柄复用、最小化时明确报错，不切到前台、不回退到整个桌面。
- 普通窗口使用 Pillow 窗口截图；全黑的 GPU 窗口使用 Windows Graphics Capture。图形捕获依赖 [windows-capture](https://github.com/NiiightmareXD/windows-capture/tree/main/windows-capture-python)，归入 desktop 可选依赖及桌面端依赖安装入口。
- Electron 捕获只接受精确窗口 ID 或唯一的完整标题；找不到目标时显示错误。
- 画面只在内存传递；每次图形捕获在拿到一帧或超时后停止。隐藏页面/关闭预览不再轮询，暂停或结束时保留最后一次预览。请求完成后检查目标代次，防止旧画面覆盖新目标。
- 应用图标从宿主读取，不用第三方 favicon 服务。图标不可用时显示应用/浏览器通用图标。

## 可点击引用

工具输入及结构化结果里的应用、URL、文件路径渲染为资源标签。主对话保留紧凑视图，不重复展开搜索结果或爬虫中间文件；标签点击不触发工具详情。

Markdown 文件链接和路径行号也使用同一文件入口，支持 Windows 路径、中文、空格、行范围。相对路径绑定当前工作目录；读取时携带当前 thread_id，沿用服务端范围与身份校验。文本按行预览，图片/PDF预览，其他常见附件提供下载。生成产物仍沿用产物工作台。

## 验证与边界

已覆盖目标关闭/复用、GPU 黑图回退、切换目标时的迟到请求、浏览器页签捕获、文件作用域、读取失败、媒体类型与预览大小限制。浏览器实机回归使用真实宿主窗口画面和真实项目文件，执行状态为测试夹具，不调用模型。

窗口被最小化、应用禁止捕获、操作系统不提供图像时会显示原因。未验证所有 CAD、远程桌面及受保护视频窗口；本次未构建安装包。Windows 打包环境需安装 desktop extra，并保留图形捕获依赖。
