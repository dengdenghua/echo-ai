## 钉钉配置隔离增量

连接器登录/状态/退出登录与 Echo 的直接 `dws`、`dws.cmd`、`dws.exe` 前台/后台命令，共用 `connector-profiles/dingtalk/home` 下的 HOME、USERPROFILE、XDG 和 AppData 配置路径；当前 Echo 用户存在时按 tenant/actor 分区。不迁移宿主原有登录凭据，启用新代码后需要在 Echo 中重新登录。
