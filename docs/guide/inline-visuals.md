# 对话可视化

Echo 在流程、关系、空间和参数变化用图更清楚时主动选择可视化。简单事实保持文字，简单结构使用 Mermaid；定制图形使用 SVG，有交互价值时使用 HTML。规则同时进入文本协议和原生工具调用的系统提示。

## 轻量入口

- `visual_guidelines(module)`：按需读取 `diagram`、`interactive`、`chart` 或 `layout` 指南。
- `show_visual(title, code, format)`：提交完整 SVG / HTML，最多 100000 字符。代码留在持久化工具参数中，结果只返回小型回执元数据。
- `visual_status(visual_id)`：查询当前任务的浏览器回执；不轮询等待。

这些入口复用现有注册表、权限过滤、消息传输和前端，不启动新的 MCP 或渲染服务。详细指南不会常驻系统提示。

## 展示与反馈

图形位于对话中，不随过程日志折叠而隐藏。生成中的预览经过清洗且不运行模型脚本；成功提交的完整 HTML 可以在不带 `allow-same-origin` 的沙盒 iframe 中运行内联 JavaScript。CSP 禁止外部资源、网络请求、嵌套页面和表单提交；宿主不执行模型脚本。容器按内容调整高度，上限 1200px，其余内容可滚动。

浏览器桥接验证 iframe 来源与每次渲染的随机通道，只接受尺寸和展示状态。回执通过认证 API 上传，并额外绑定随机回执令牌、租户和用户；Agent 查询还绑定任务。令牌不会进入 iframe。回执是浏览器观察结果，不能证明内容正确、图形清晰或标准合规。

- `pending`：仅接受了载荷，尚无浏览器回执。
- `rendered`：浏览器完成初次绘制，暂未报告错误。
- `error`：脚本、资源或 CSP 报错；同一载荷的错误不会被后来的成功覆盖。
- `unknown`：不存在、超出当前任务/所有者范围、已过期或后端重启。

回执进程内保存一小时、最多 512 条，不存代码。多进程服务需要粘性路由或未来接共享存储；当前本地单进程无需数据库变更。网页关闭后不保证产生回执。浏览器可显示本地结果，但回执上传失败会明确提示，Agent 不应宣称已收到。

“保存为产物”把保存请求提交给当前任务，由 Agent 使用现有文件工具写入任务工作区，再使用既有 HTML 产物预览、编辑和修订流程。“请求修复”发送图形 ID 与错误信息，修正时创建新载荷。

## Mermaid

支持缩放、适应宽度、浅/深主题及 SVG/PNG 下载。配置和渲染串行执行，避免多个图块主题互相污染。保留严格安全模式、SVG 清洗、生成期间源码显示和失败回退。PNG 导出最长边限制为 4096px。

## 验证与生效

后端测试覆盖参数校验、权限、任务隔离、令牌、回执顺序、过期与数量上限；前端测试覆盖持久化消息、折叠日志、静态预览及回执桥。Playwright 使用真实 Chromium 验证交互、宿主隔离、CSP 和延迟报错。正式使用需运行包含本次修改的后端与前端；开发前端可热更新，后端工具注册和提示规则需要重启加载。
