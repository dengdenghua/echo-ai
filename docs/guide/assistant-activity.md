# 助手活动

在 Echo 助手对话顶部点击「活动」，查看当前执行主机中的运行、项目任务和群协作任务。手机上入口显示为活动图标。

面板提供「全部」「正在处理」「需关注」「已完成」筛选，也可搜索任务标题、项目、群组、角色名称或状态。搜索可与筛选组合，计数仍以最近读取的记录为准。角色使用已有展示名称；已知状态显示中文或英文说明，悬停可查看原始状态值。暂停、等待确认、失败、中断及取消等状态进入「需关注」；卡片保留来源任务的状态与原因。关联运行结束不会直接完成项目任务，卡片会说明项目任务仍未完成。完成记录仍需打开来源核对成果。

「打开来源」回到已有对话；项目任务同时展开项目工作台。无法确认原对话的旧记录仍显示活动，但来源按钮禁用。打开面板不会创建任务、会话或项目，也不会自动批准、恢复或重跑工作。

活动只从现有账本读取：Project OS 项目任务、CollaborationStore 群协作任务和 TaskSupervisor 执行记录。项目在协作账本中的投影及具有可靠来源坐标的关联运行会合并，标题相同本身不会触发合并。

面板首次打开时读取，打开期间每 15 秒更新，也可手动刷新。刷新失败会明确标注，并保留当前账号、当前主机上次读取的记录与最后成功读取时间。旧服务缺少接口、登录失效、权限不足和主机断连各有对应提示。切换账号或执行主机使用独立缓存，并清空搜索和筛选，不沿用另一个来源的数据。

## 接口约定

`GET /api/assistant/activity?limit=100` 返回 `echo.assistant_activity.v1`。`limit` 范围为 1–200，默认 100。优先列出需关注和正在处理的记录，各类中按更新时间降序排列；`summary` 只统计本次返回的记录，`has_more` 表示还有未列出的记录，因此筛选计数不是整个历史账本的总数。

启用鉴权时，接口只返回本人拥有或能够证明参与的工作，并校验租户和群历史授权。管理员的个人助手同样受个人参与范围限制。接口不接受 `owner_id` 指定其他人。客户端通过现有本地或远程网关读取，来源跳转继续使用同一主机。

运行账本在每次请求中只完整读取一次，不会因分页重复扫描或截掉较早的待处理任务。群状态和成员授权只在当前请求内复用，下一次刷新重新检查。已被权威成员记录授予访问、但本地房间投影尚未同步的活动可继续显示真实房间 ID；未同步的名称留空。

这是一层现有工作记录的只读视图，不是新增任务账本，也不包含自动通知、休眠唤醒或额外的云端执行服务。
