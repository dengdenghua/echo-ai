# 隔离任务与编码工具箱

在对话顶部的环境与来源菜单中，选择「隔离任务 · Worktrees」。选择了 Git 项目时才显示此入口。

选择起始分支后，「创建并打开新任务」会在当前 Echo 服务的 `data/worktrees/` 下创建独立目录及 `echo/task-…` 分支。新任务绑定返回的目录；原有聊天和工作区仍保留。已存在的工作区可以直接在新任务中复用，服务重启后也能重新发现这些目录。

新目录只包含起始分支已提交的文件。未提交的修改、未跟踪文件和忽略文件不会自动复制。目录、Git 操作及模型执行都发生在所选 Echo 服务所在的电脑上。

此入口支持本机或明确允许本地工作区访问的独享服务。共享服务必须先有独立的工作区分配与权限关联，因此当前会拒绝此操作。源项目及目标目录均受现有文件系统路径边界约束。

这一版提供创建、发现和复用；合并修改、归档和恢复仍使用现有 Git 工具，没有自动清理或自动合并。

列表仅在打开面板时查询。创建不自动重试；如果响应丢失或请求失败，先刷新已有工作区，确认是否已经创建。关闭面板、切换项目或执行主机后返回的旧创建结果不会自动打开任务。可以复用已存在的目录；不会自动合并、删除或归档。

插件与应用兼容性使用 `runtime/platform/plugins/host_api.py` 的 `HOST_API_VERSION`，当前为 `0.2.0`。它与 Runtime 发布版本独立，健康接口在 `runtime.hostApiVersion` 报告这个值。发布版本变化不应自动改变插件协议；签名、权限、依赖和版本要求仍正常校验。
