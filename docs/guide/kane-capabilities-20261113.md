## 账号切换故障
旧日志明确记录 App Server frame exceeded stream limit，随后 account、usage、rate-limits 等接口连续 503。旧 UI 将查询失败视为整个面板不可用，并用缓存账号显示已连接。
已将账号控制连接失效时重建、连接器分页从 100 改为 10（总上限不变）；没有取消消息大小上限。界面不再用绿色缓存状态掩盖错误，授权操作不被模型配置读取失败遮挡，按钮明确显示切换账号。
已在新 Windows AI 安装版实际打开 设置→模型→高级设置→Codex 授权：账号信息加载、切换账号按钮可见，无原配置错误。只检查入口，不替用户退出或提交新账号登录。

## 边界与交付方式
Windows 安装器为未签名本地体验版；Linux tar.gz 是现有开发环境增量，不是系统镜像。当前机器能力已安装；新机器还需按使用说明配置宿主软件并执行独立能力安装步骤。不是复制 Codex 云端专属能力、登录授权或模型权重。
旧 Workbench 与 1.5GB 镜头库保留原适配器和数据，本次未覆盖、合并或宣称已同步它们；新增的增量导入针对 Codex 本地 optical-workflow-memory 库。尚未完成三个引擎各发起一次真实工程任务的端到端验收，也未重做全部原生 CAD 求解、跨网或真机测试。

当前 Windows AI 已保持运行并停在 Codex 授权面板。原安装包、私人记忆与必要迁移回退保留。
