# Office、PDF 与 HTML 产物协作

Echo 的办公能力由本地插件和产物工作台共同提供。它不是跳转到外部 WPS 网页，也不要求把文件上传到第三方服务。

## 开始使用

1. 在 **HUB → 应用** 确认 `Documents`、`Spreadsheets`、`Presentations` 或 `PDF` 已启用；桌面完整包默认内置这些插件，精简部署可按需安装。
2. 在任务中直接说“生成一份 Word 报告”“把这个 Excel 的 Forecast!C5 改成 120”或“把第三页改成风险矩阵”。
3. Agent 返回文件后，在产物面板打开它。Office 文件默认显示原貌预览；支持结构定位的格式还可以点击 **选择内容**，选中页、段落或单元格后再交给 AI 修改。

插件在启用后向 Agent 注册工具，不会扫描或自动接管本机其他 CLI。

## 支持范围

| 格式 | 创建 | 读取/分析 | 修改 | 产物预览 |
|---|---:|---:|---:|---:|
| `.docx` | 是 | 是 | 原位文本修改 | 原貌＋结构预览 |
| `.xlsx` / `.xlsm` | 是 | 是 | 原位单元格、公式和格式修改 | 原貌＋单元格选择 |
| `.pptx` | 是 | 是 | 按页原位文本修改 | 原貌＋页面选择 |
| `.pdf` | 是 | 是 | 生成新版本、合并、拆分 | 原貌预览 |
| `.csv` / `.tsv` | 是 | 是 | 精确文本修改 | 结构预览 |
| `.doc` / `.xls` / `.ppt` | 否 | 依赖本机 Office 转换器 | 转为 OOXML 新版本后修改 | 转换器可用时原貌预览 |

旧版二进制 Office 文件不会被伪装成“原位修改成功”。转换器不可用时，Agent 会明确说明，并保留原文件。

## HTML 人机共改

工作区输出中的 `.html` / `.htm` 支持两种编辑方式：

- **直接编辑**：在渲染页面上修改文字和结构，保存回原产物；支持撤销上次保存。
- **AI 选区修改**：点击页面元素并描述要求，先创建工作副本，再让 Agent 修改副本中的目标元素及必要样式。任务结束后打开 **待审修改** 比较差异，点击 **接受修改** 才会替换正式文件；**拒绝修改** 保留正式文件。

待审记录保存在任务目录中，刷新后仍可打开。副本没有变化、任务仍在运行或正式文件已更新时，不能接受。比较后副本又变化时，服务端要求重新比较，不会接受未经查看的版本。接受前自动保留正式文件的旧版本，可通过 **版本历史** 恢复。

接受过程中断时，会按文件实际内容核对状态，不会在重试时再次写入旧修改。修改已接受后又恢复旧版本，重新打开这条修改记录不会重新应用它。模型如果只输出工具调用样式的文本而未执行，不能视为副本已修改。

在未编辑状态下点击 **版本历史**，可以查看此前通过产物接口保存的旧版本，刷新页面后仍然可用。选择版本后显示与当前内容的只读差异；点击 **保留当前版本** 不会修改文件，点击 **恢复此版本** 才会恢复。

恢复前会将当前内容存为一个新版本，因此可以再次进入历史找回恢复前的内容。超过 20 份的旧版本也会保留，较早版本分页加载。此前已被旧策略清理的版本无法重新生成。Agent 或外部编辑器直接写入文件的每一次修改，目前不会自动进入这份历史。

直接编辑采用版本校验。如果 Agent 在你编辑期间更新了同一文件，界面会提示冲突，不会静默覆盖任何一方。带有未保存修改时，关闭产物、切换文件或离开页面都会收到保护提示。

## 文件安全与恢复

- Office 写入先保存到同目录临时文件，再原子替换正式文件，进程中断不会留下半个 ZIP 包。
- 原位修改默认创建带时间戳的相邻备份。
- 工具只能读写当前任务允许的工作区路径。
- HTML 保存使用内容哈希做乐观并发校验，并保留可恢复版本。
- HTML 保存和恢复在接口内共享文件锁；冲突时不覆盖当前文件。历史读取和恢复沿用任务所有权检查，损坏或被改写的备份不会直接恢复。
- HTML 待审接口沿用任务所有权、路径边界和同一文件锁。此流程用于预览页发起的选区修改，不是新的文件系统权限边界；具有目录写入权限的外部命令或 Agent 直接写入仍不受这份提案状态机约束。

## 当前边界

Office 产物提供的是“高保真预览＋选区 AI 修改”，不是内嵌一套完整 WPS。当前没有多人同时光标、批注线程、修订模式，也不能在 PowerPoint 画布上直接拖拽每个形状。需要这些能力时，可在保留原文件的前提下用本机 Office/WPS 打开；Agent 仍可继续读取和修改保存后的版本。
