# 群聊与执行面板整理

## 修复

- 群聊镜像去重同时识别 `thread:`、`thread:agent:`、`thread:error:` 来源，使用已加载的原始条目 ID，覆盖被合并到过程回放中的消息。未加载的远程消息继续显示。
- 历史消息中的 `None`、`null`、`undefined` 名称回退到成员名称。
- 执行面板四个次要操作收进“更多操作”菜单，成员名称可以截断，主电脑入口保持可见。
- 真人头像点击提及本人，不再构造 AI 执行面板；没有实际执行记录的 AI 使用等待状态。
