# 任务交互与交付检查

## 入口与行为

- 执行中的输入框支持“现在补充”和“稍后执行”。前者使用已有 steer 通道，只有服务端接收成功后才显示回执；回执不代表模型已执行。
- 稍后执行按当前任务排队，一轮完成后发送一项。队列可编辑、删除、暂停；断网时保留，任务失败、停止或刷新恢复后暂停，必须手动继续。队列仅保存在当前浏览器标签的 sessionStorage，最多 20 项，仅支持文字，发送时沿用当前任务设置；不是服务端后台调度。
- 消息的更多/右键菜单提供“在旁路追问”。点击仅打开面板，用户发送后才从已完成历史派生独立任务，以计划模式解释。主任务继续执行，追问结果可引用回主输入框，不会自动发送或应用。收起面板不停止追问，可打开独立任务继续处理。计划模式不等同于操作系统强制只读隔离。
- 文件预览支持选中文字并引用行号、路径和预览内容摘要；引用进入草稿，不直接发送。摘要针对读取到的预览内容，不是服务端文件版本。
- 图片预览支持拖拽框选、清除和引用整图。引用保留文件路径与相对图片左上角的百分比坐标，不创建裁剪图片或自动上传附件。PDF 支持手动指定页码、定位与引用，内嵌阅读器翻页不自动同步页码；PDF 区域框选和表格单元格批注尚未包含。
- “本轮交付”从结构化工具记录展示文件操作、已有差异和验证。仅完成状态且结构化退出码为零的验证标为通过；模型文字不构成测试证据。预览读取当前文件，差异保留当轮记录。
- 协作交接的文件可打开预览，任务来源和目标可定位到协作任务卡。失败任务在折叠摘要显示数量；接收确认与验证通过保持独立含义。
- 交付恢复操作失败时保留记录并提示重试，旧任务或旧请求的返回不会覆盖新页面状态。
