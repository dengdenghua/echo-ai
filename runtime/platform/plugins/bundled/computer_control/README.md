# 电脑控制

Echo 随应用交付的 ModulePlugin，使用 PluginHub 的安装、启用、停用、卸载入口。
保留现有工具 ID；卸载保存用户数据，重新安装可恢复。

可选依赖使用项目的 `desktop` extra（PyAutoGUI、Pillow、Windows UIAutomation）。
缺失依赖时，对应驱动返回不可用提示；不在插件启动时安装软件或申请系统权限。
视觉循环由宿主注入视觉模型。HTTP、Electron IPC 和设备传输仍是宿主服务。

停用会注销工具并撤销缓存处理函数，阻止新的 HTTP 自动化请求。
已经进入驱动执行的动作不强行中断；不关闭用户的桌面应用。

视觉循环在截图前、模型返回后与动作执行前检查本次激活的撤销状态。
等待期间每 100 毫秒检查一次。停用后即使重新启用，旧循环也不能恢复；
已经发出的模型请求或系统调用会先返回，随后停止后续动作。

设置页的「执行条件检查」只检查驱动和连接，不截图、不点击、不调用模型。
「驱动可用」不表示桌面会话、系统权限和完整任务已验证。
